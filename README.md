# astro-orbit-platform
Astro-Orbit PlatformA high-performance property booking and concierge management platform powered by PostgreSQL and Neon.FeaturesUser Management: Multi-role access control supporting Travelers, Hosts, and Admins with dedicated user profiles.Property Listings & Media: Support for property attributes, pricing, spatial coordinates via PostGIS, and image asset association.Conflict-Free Booking System: Advanced PostgreSQL range types (daterange) and EXCLUDE constraints to prevent double-booking.Concierge & Tour Services: Integrated tour guide directories, concierge service management, and booking request workflows.Financial Operations: Transaction tracking, promotional discount enforcement, and secure host payout configurations.Tech Stack & Database ArchitectureDatabase Engine: PostgreSQL 15+ (Hosted on Neon)Extensions Used:postgis — Spatial data types and coordinate indexinguuid-ossp — Automatic UUID v4 generationbtree_gist — Indexing support for range-exclusion constraintsDatabase Setup & Schema MigrationOption 1: Execute via CLI (psql)To avoid web console UI query history truncation and character limits, execute the schema script directly through the terminal:Bashpsql "postgresql://<USER>:<PASSWORD>@<NEON_HOST>/<DATABASE_NAME>?sslmode=require" -f schema.sql
Option 2: Execute via Database GUI (DBeaver / TablePlus / pgAdmin)Copy your Neon PostgreSQL connection string.Open your database client and establish a connection using the URI.Open a new SQL Editor session, paste the contents of schema.sql, and select Execute as Script (Alt + X in DBeaver).Database Schema StructureTable / RelationDescriptionusersBase identity table storing credentials and user roles (TRAVELER, HOST, ADMIN).property_listingsCore listings data including location points (point) and base nightly rates.bookingsReservation logs featuring double-booking prevention via GiST exclusion indexes.transactionsPayment records linked directly to reservations.reviewsSingle-review per booking constraint enforcement (rating 1–5).concierge_servicesOfferings for extra guest services with dedicated status tracking.tour_guidesDirectory of local guides with spatial search indexes.Views & Analytical Modelsview_active_bookings_with_price: Calculates total nights spent and total price for reservations.view_travelers: Synthesizes traveler profiles with user identity data.view_hosts: Aggregates verified host profile details.listing_summary: Computes average review ratings and total review counts per listing.Environment SetupCreate a .env file in the project root:Code snippetDATABASE_URL=postgresql://<USER>:<PASSWORD>@<NEON_HOST>/<DATABASE_NAME>?sslmode=require
