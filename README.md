# astro-orbit-platform
This is a software engineering project prototype for Astro Orbit - it is a hotel booking, property management and travel service professional platform showing a Node.js/Express backend API, frontend components, and a normalized PostgreSQL database schema.

 Team Contributions
 Safim
 Frontend & UI Prototypes: Developed the client-side user interface prototypes (frontend/index.html, frontend/login.html), including the main portal landing view, search bar widget, and user role selection views.  
 Alpona
 Backend & Business Logic: Implemented the Node.js/Express API routing, core controllers (BookingController.js, ListingManagementController.js, SearchController.js), DTO validation layers, and service orchestration modules (BookingTransactionManager.js, ImageProcessingService.js).  
 Daniel Rion Majumder
 Database Architecture: Designed and implemented the complete PostgreSQL database schema (database/schema.sql), including core relational tables, specialized subclass inheritance views (view_travelers, view_hosts), spatial GiST indexing for map coordinates, and B-Tree date-range optimization indices.
